# sql-70-questions-practice
Practising SQL through 70 hospital database questions, documenting solutions, query logic, and lessons learned.

## About This Project

This repository documents my hands-on SQL practice while working through a 70-question hospital database challenge.

My goal is to strengthen my SQL problem-solving skills and prepare for Data Analyst roles by solving problems independently, explaining my queries, and reviewing mistakes.

## Database Overview

The practice environment shown in my learning resource includes tables such as:

- `patients`
- `admissions`
- `doctors`
- `province_names`

The exact schema, relationships, and column definitions will be documented after reviewing the database structure.

## Learning Objectives

- Write readable and accurate SQL queries.
- Filter and sort records.
- Aggregate data to answer questions.
- Work with related tables using joins.
- Practise more advanced SQL concepts as they appear in the challenge.
- Improve debugging and problem-solving skills.

## Repository Structure

SQL solutions are organized into numbered files so each question can be located easily.

Each solution will include the question, SQL query, explanation, and any important learning points.
