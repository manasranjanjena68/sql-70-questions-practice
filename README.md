# SQL 70 Questions Practice

**Practising SQL through real-world database scenarios, solving problems, documenting queries, and developing analytical thinking.**

## About This Project

This repository documents my hands-on SQL learning journey through a 70-question SQL practice challenge using two databases: **Hospital Database** and **Northwind Database**.

My goal is to strengthen my SQL problem-solving skills, understand relational databases, and prepare for Data Analyst roles by solving problems independently, testing queries, and documenting important learning points.

## Databases Overview

### 1. Hospital Database

The Hospital Database contains information about patients, admissions, doctors, and provinces.

**Main tables:**
- `patients`
- `admissions`
- `doctors`
- `province_names`

**Focus Areas:**
- Patient data analysis
- Admission analysis
- Doctor and patient relationships
- Aggregation and filtering
- SQL joins and subqueries
- Window functions

### 2. Northwind Database

The Northwind Database is a sample business database used to practise SQL through business-related scenarios.

**Main tables:**
- `customers`
- `employees`
- `orders`
- `order_details`
- `products`
- `categories`
- `suppliers`
- `shippers`
- `regions`
- `territories`
- `employee_territories`

**Focus Areas:**
- Sales and revenue analysis
- Customer behaviour analysis
- Product and category performance
- Employee performance analysis
- Order and shipping analysis
- Business-oriented problem-solving

## Learning Objectives

Through this challenge, I aim to:

- Write readable and accurate SQL queries.
- Filter, sort, and manipulate data.
- Perform aggregations using GROUP BY and HAVING.
- Work with related tables using different types of JOINs.
- Understand subqueries, CTEs, and window functions.
- Analyse business data and identify meaningful insights.
- Improve debugging and problem-solving skills.

## My Learning Approach

I attempt each question independently before reviewing hints or solutions.

My process includes:

1. Understand the problem statement.
2. Identify the required tables and columns.
3. Write the SQL query.
4. Execute and verify the result.
5. Review mistakes and improve my understanding.
6. Document the solution and important learning points.
